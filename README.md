# SkillCraft Technology - Software Development Internship

## Task 1: Temperature Conversion Program

### 📌 Project Description
This repository contains my submission for **Task 1** of the Software Development Internship at **SkillCraft Technology**. 

The program is a temperature conversion utility that allows users to input a temperature value and seamlessly convert it between Celsius, Fahrenheit, and Kelvin scales.

### 🚀 Key Features
*   **Multi-Scale Conversion:** Supports Celsius, Fahrenheit, and Kelvin inputs.
*   **User Input Processing:** Prompts users for values and the target scale unit.
*   **Accurate Formulas:** Uses standard mathematical conversion formulas for precision.

### 🛠️ Tech Stack
*   **Language:** Python
